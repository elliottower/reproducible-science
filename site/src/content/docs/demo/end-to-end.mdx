This notebook demonstrates `repro` — [see documentation](/reproducible-science/tools/repro/).

1. Seals a run and binds a manuscript claim to the output it produced.
2. Declares what the manuscript says in `repro.yaml`, and checks it.
3. Changes the number, and gets a mismatch — the artifact was read and disagreed.
4. Changes the address, and gets `not_found` — nothing was compared, so nothing disagreed.
5. Deletes a ledger entry, and watches `reanchor` refuse to record the damage.
