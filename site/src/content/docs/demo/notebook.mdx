there is no account to create.

## What this can and cannot do

WASM has no process model, which decides the boundary:

- **`results` runs completely** — the ledger, the hash chain, the anchor, the tamper checks.
  It shells out to nothing.
- **`repro verify` runs** for tree, table and array locators.
- **`prereg freeze` does not run.** It requires a real git commit, and there is no git here.
- **`citations` against a PDF does not run.** It needs `pdftotext`.

Rather than fake those, they are left out. A demo that quietly skips the checks it cannot
perform is the exact failure the tool exists to report.
