A paper quotes something. `citations` reads the source and reports whether the passage is
there — and whether the file it read is the file the record pinned.

This notebook runs a quotation that resolves, one that does not, a source edited after it was
pinned, and a passage claimed on the wrong page. It covers a text source and a PDF.

## PDFs

The published package reads a PDF by calling `pdftotext`, which is a binary. This notebook
substitutes a pure-Python extractor for that one function; every other part of the package is
the published code.
