A paper quotes a source. `citations` reads that source and reports whether the passage is in
it, and whether the file it read is the file the record pinned. This notebook runs a quotation
that resolves, one that does not, a source edited after it was pinned, and a passage claimed
on the wrong page, against a text file and a PDF.

## Not possible in WebAssembly

`citations` reads PDFs by calling `pdftotext`, a compiled binary with no WebAssembly build.
The notebook swaps a pure-Python extractor into that one function; the rest is the published
code.
