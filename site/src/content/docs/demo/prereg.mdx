This notebook demonstrates `prereg` — [see documentation](/reproducible-science/tools/prereg/).

1. Scaffolds a plan in the 27 OSF question titles.
2. Runs `check` before anything is frozen, and gets *not frozen* rather than *unchanged*.
3. Appends an amendment to the log, and gets a note refused for spanning two lines.
4. Tries to freeze, and gets refused for want of a commit to anchor to.

## Not possible in WebAssembly

A freeze names the commit the plan was frozen at, and git does not exist in WebAssembly. The
notebook ends on `prereg freeze` refusing rather than recording a freeze that names no
commit — install locally to complete it.
