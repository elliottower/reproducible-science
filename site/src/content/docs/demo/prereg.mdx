This notebook demonstrates `prereg` — freeze a plan before you run it, and record what
changed after. It scaffolds a plan in OSF's 27 question titles, shows what `check` says
before anything is frozen, and appends to the log.

## Not possible in WebAssembly

A freeze names the commit the plan was frozen at, and git does not exist in WebAssembly. The
notebook ends on `prereg freeze` refusing rather than recording a freeze that names no
commit — install locally to complete it.
