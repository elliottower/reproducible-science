This notebook demonstrates `citations` — [see documentation](/reproducible-science/tools/citations/).

1. Resolves a quotation against the source it names.
2. Reports a passage that is not there as absent, which is not the same as unchecked.
3. Catches a source edited after it was pinned.
4. Flags a passage claimed on the wrong page.
5. Does all of it again against a PDF.

## Not possible in WebAssembly

`citations` reads PDFs by calling `pdftotext`, a compiled binary with no WebAssembly build.
The notebook swaps a pure-Python extractor into that one function; the rest is the published
code.
