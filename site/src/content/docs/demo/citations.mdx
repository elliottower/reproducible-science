This notebook demonstrates `citations` — read the source a paper quotes and report whether
the passage is in it, and whether the file read is the file the record pinned. It covers a
quotation that resolves, one that does not, a source edited after it was pinned, and a
passage claimed on the wrong page.

## Not possible in WebAssembly

`citations` reads PDFs by calling `pdftotext`, a compiled binary with no WebAssembly build.
The notebook swaps a pure-Python extractor into that one function; the rest is the published
code.
