This notebook demonstrates `results` — an append-only ledger of what you sealed before a
run, what the run produced, and which manuscript claims rest on which run. It ends on the
ordering guard: once you record that the outcomes were seen, a run performed afterwards can
no longer back a confirmatory claim.
