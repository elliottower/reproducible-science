# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/),
version 2.1.

In short: be civil, assume good faith, and keep criticism directed at the work. Harassment,
personal attacks and discriminatory language are not acceptable in issues, pull requests,
commit messages or any other project space.

Report a concern to <elliot@elliottower.ai>. Reports are handled privately.
