**The `repro` mod shows fix requests sent from the lineage view.** A request the "Fix with Claude Code" button appends to `~/.claude/repro-fixes/queue.jsonl` is drawn as one more row of the band above the prompt, with "Load into prompt" and "Dismiss", in a session whose folder is that project or that has worked in it. Loading fills the prompt box and sends nothing. `/repro-fixes` lists the requests and `/repro-fixes load` fills the oldest; handled ids go to `~/.claude/repro-fixes/handled.json`.
