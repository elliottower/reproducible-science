**The bundled plugin installs in Codex.** `packages/repro/plugin` carries a `.codex-plugin/plugin.json` beside its Claude Code manifest, over the same `skills/`, and `.agents/plugins/marketplace.json` lists it, so it installs with `codex plugin marketplace add elliottower/reproducible-science` and then `/plugins` inside Codex. Codex gets the seven skills, the `repro` MCP server started as `repro mcp`, and the five hooks. Because Codex edits files with `apply_patch`, whose hook input is the patch text, `hooks/codex_apply_patch.py` runs each edit hook once for every file a patch touches, with the input Claude Code would have sent; an edit, deletion, overwrite or move of a frozen plan or a frozen amendment is refused, in the words Claude Code uses, and refused too where the check on a possibly frozen file cannot run. A move or deletion done with a shell command such as `mv` or `rm` is not seen. `scripts/versions.py` writes the new manifest's version with the others.
