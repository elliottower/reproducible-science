**`repro check` is removed. `repro verify` checks what it checked, and the claims, in one report.** There is no alias: `repro check` now exits 2 with argparse's `invalid choice`. `repro verify <dir>` takes the directory `repro check <dir>` took. `--only` has no counterpart: each tool's own command, or `repro <tool>`, runs one. Where a project keeps no manifest, `repro verify` still runs the other tools and exits on what they found.
