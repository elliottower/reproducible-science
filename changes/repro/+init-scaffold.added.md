**`repro init` in a project with result files and a manuscript and no `repro.yaml` also drafts its claims, and verifies none of them.** It writes `repro.draft.yaml` and `open-items.json` at the top of the project, in the format `claims from-codecheck`, `claims from-corebench` and `claims from-clawbio` write. The draft pins the result files and the manuscript `repro verify` finds with no manifest, under the ids `repro manifest init` gives them, and declares one claim per number the manuscript prints, with the sentence holding it as the text, across line breaks, and no assertion. For a `.tex` manuscript the numbers are read from the source, with comments, the preamble and the arguments of commands such as `\label` and `\cite` removed, so numbers in tables and inline math are included and each claim's line is its source line. Each claim has one item asking for the address of its value, listing as candidates every place the result files hold the number, as `repro verify` compares it with no manifest. An item is `unique` where exactly one candidate passes the CORE-Bench reader's guards, applied to the words before each number in its own clause; a candidate in an index-like column or key never passes. `init` prints `scaffolded, nothing verified: N numbers left open, M with one candidate`, and as the next step to fill the items with an agent (the `open-items` skill, or the tools of `repro mcp`), review the draft and rename it to `repro.yaml`. The draft fails `strict` until filled. No starter `repro.yaml` is written beside a draft, so there is one manifest to rename; with nothing to scaffold, or with `--no-scaffold`, the starter is written as before. Where `repro.yaml` exists `init` scaffolds nothing and says so; where either scaffold file exists it writes no starter, names that file, and replaces neither without `--force`; it writes nothing through a symbolic link at either name, dangling or not, and lists a result file that is a symbolic link as not checked; `--no-scaffold` skips the scan. `repro manifest init` is unchanged. `claims.open_items.write_draft` takes `overwrite` and refuses an output path that is a symbolic link or resolves outside its directory. `claims.starter.scan` returns the survey with every number of the manuscript it was to compare, the first `survey.compared` of them compared, and with `tex_source` reads a LaTeX manuscript's source lines. `repro init`, and `prereg new` under it, write no `.gitignore` through a symbolic link at that name, dangling or not; `init` says it left the file alone.
