**`repro mcp` works from the base install.** The MCP SDK, still pinned to its 2.2.0 release, is a dependency of `reproducible-science` rather than of its `mcp` extra, so `uv tool install reproducible-science` is the whole install line. The `mcp` extra is kept and empty, so `reproducible-science[mcp]` still resolves, and `[all]` no longer names it. No other command imports the SDK: `repro` loads it only when `repro mcp` runs.
