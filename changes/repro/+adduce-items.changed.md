**The adduce rule `R-REPRO-001` reports each checked assertion as an item of its finding.** Each item carries the assertion's id (claim, kind, name, position), a status read from its check record (`pass` for a match, `fail` for a mismatch or an address holding no value, `unknown` where nothing was compared), the printed and stored values, the comparison rule, the validity of each file read, and the manifest line and files it read, located from the repository root; an item that did not hold names `repro why` for its claim. adduce never scores an item, so the finding's status and weight are unchanged. Past adduce's envelope of 10,000 items the finding says how many assertions are left to `.adduce/repro-report.json`, which is still written in every case. The `adduce` extra now asks for `adduce>=0.2`, the first release with finding items.
