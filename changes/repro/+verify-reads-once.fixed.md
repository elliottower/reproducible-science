`repro verify` reads each artifact once in a run. A manifest with many claims over one table parsed the table, and extracted the document's text, once for every claim, and scanned every row for each; checking 1,000 numbers bound to one CSV took about fifteen times as long as it now does. A second verification in the same process still reads every file again. The manifest itself is read with libyaml's loader where PyYAML has it.
