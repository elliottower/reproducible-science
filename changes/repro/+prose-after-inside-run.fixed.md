**A `prose` locator reads a number printed against the text that follows it.** The value was the whole run of non-whitespace characters after `before`, and `after` had to begin past it, so a cell of a printed table, `| 3| 0.459| 0.124|`, was read as `0.459|` and reported `value_not_numeric` whatever `after` said, and `93.1%` and a number closing a sentence could not be bound either. The value is now the longest run following `before` that `after` follows: the whole run where `after` begins past it, and otherwise the run cut at the last place inside it where `after` begins, so `before: "| 3|", after: "|"` reads `0.459` and `after: "."` reads `3.14.` as `3.14`. A locator that resolved before resolves to the same value, and with `after` omitted the run is still read whole. Three conformance fixtures cover a printed table, and declare the three stages as well as the outcome.
