**`repro verify` checks every record a project keeps, in one report with one exit code.** Beside the claims `repro.yaml` declares, which it checks as before, it runs `prereg check`, `results verify --files` and `citations verify --claims <dir>` where the project keeps a plan, a ledger or a claims directory, grades each declared command against the record of its re-runs as `repro stale` reports it under `--policy`, and fails a ledger claim naming a freeze that no frozen plan records. A record the project does not keep is named as not used and is not run. It executes nothing a manifest declares and reaches no network; `repro reproduce` remains the only command that runs anything. A directory may be given in place of the manifest, and names the project. It exits 0 where every check that ran passed, 1 where one failed or could not check, and 2 where nothing was checked: no manifest and no other record. Its options are the ones it had, and `--format json` keeps `report` and `assessment` where they were and adds `staleness`, `prereg`, `results`, `citations`, `cross_tool` and `project` beside them; `project.checks` gives each section `passed`, `failed` or `not used`, and a tool `could not check` or `nothing to read` where its own check said so; both count against the exit code. `--format sarif` is the claims' log with each section's verdict and the exit code under the run's `properties.checks`. With no manifest and another record kept, the text reports the claims as a section not used; with nothing to check it prints what `claims verify` prints and one line naming the sections not used. `claims verify` is the claims alone and the fast check: the published pre-commit hooks `repro-verify` and `repro-verify-strict` now run it, as do the Claude Code mod's status row, `repro ci claims` and the claims step of `repro audit`, which is now named `claims.verify`. The `/repro-check` command runs `repro verify`. `repro claims` runs `claims`, for an install that put only `repro` on PATH, as `uv tool install reproducible-science` does without `--with-executables-from claims-cli,prereg,results-cli,citations`; the mod's status row falls back to `repro <tool>` for a tool not on PATH and says `not installed`, never `not read (timed out)`, for one it cannot run.
