**[reproducible-science] `repro check` finds a paper's claims where papers keep them, and tells `citations` where they are.** A project holding sixty-one pinned quotations at `paper/prior_art/claims` was told no tool applied to it, because detection looked only at the repository root. A project with `claims/` at its root fared worse: the check ran `citations verify` with no claims directory, which reports nothing to check and exits 2, so it was reported as FAILED.
