**`repro mcp` runs an MCP server over standard input and output, so any coding agent that speaks MCP has the toolkit's checks as tools.** It needs the `mcp` extra, `reproducible-science[mcp]`, which pins the official Python SDK to its 2.2.0 release; the base install is unchanged. The read-only tools are `verify`, `why`, `stale`, `numbers`, `origins`, `open_items`, `next_open_item` and `get_open_item`, which hand over one open item at a time with the claim, the printed value, the sentence and its line, and each candidate's file, address, labels and stored value, and `prereg_check`, `results_verify` and `citations_verify`. `verify` here writes no record of checks. Two tools write: `propose_binding` appends one assertion marked `basis: inferred` to a draft manifest to fill an open item and then checks it, refusing any other basis, `reviewed`, a claim the open-items file lists no item for or the draft does not hold, an assertion that fills no open item, a `reported` that is missing or other than the value the source states, an artifact the draft does not declare, a field over its length cap and a draft outside the project root; it inserts the assertion as one line and changes no other byte of the draft, comments included, and reports a match as "matched, inferred: not verified"; `pin_quote` runs `citations pin`, which writes only a quotation that resolves and refuses an id the claims file already holds. The project root is the folder `set_project` named in the session, which must hold `repro.yaml`, `repro.draft.yaml`, `.results/`, `.prereg/`, `claims/` or `PREREG.md`; else the client's first `file://` MCP root; else `--root`; else the nearest directory at or above the working directory holding one of those, and where none is found every tool answers "no project: call set_project". Every path is resolved inside it and one that leaves it, through `..` or a symlink, is refused. Nothing the server offers freezes, registers, seals, records a run, runs a declared command or reaches the network, and its instructions carry the `open-items` procedure and tell the agent to ask a person for those.
