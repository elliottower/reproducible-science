**`repro mcp` runs an MCP server over standard input and output, so any coding agent that speaks MCP has the toolkit's checks as tools.** It needs the `mcp` extra, `reproducible-science[mcp]`, which pins the official Python SDK to its 2.2.0 release. Registered once per agent, it serves every project: each call works in the project its path is in, the nearest folder above it holding `repro.yaml`, `.results/`, `.prereg/`, `claims/`, `PREREG.md` or a reader's `repro.draft.yaml`, and a call with no path takes a `project` argument or the project of the last call. Every path is kept inside its project, and a symlink belongs to the folder it sits in. The read-only tools are `verify`, which writes no record of checks, `why`, `stale`, `numbers`, `origins`, `prereg_check`, `results_verify`, `citations_verify`, and `next_open_item` and `get_open_item`, which hand over one open item at a time with the claim, the printed value, the sentence and its line, and each candidate's address, labels and stored value. `propose_binding` inserts one assertion marked `basis: inferred` into a draft to fill an item and checks it, replaces only its own earlier proposal that did not match, and refuses any other basis, `reviewed`, a claim not listed or not in the draft, a kind that fills no open item, a missing or changed `reported`, an undeclared artifact and an oversized field; a match is reported as "matched, inferred: not verified", and from the sixth attempt at one item the result carries a warning. `add_artifact` declares a file pinned by its sha256 and marked `basis: inferred`, refusing a directory, a Git LFS pointer, a file over 64 MiB and one already declared. `mark_reviewed` records what the user approved in the conversation, as `reviewed` with the git user, the time, "approved in chat via" the client and the digest of what was approved. `pin_quote` runs `citations pin`. `citations_audit` runs `citations audit --bib` over ten entries a call, with `strict` and `no_search`, and reports each as agrees, disagrees with the fields named, not found, or could not check, which is what a throttled service gives; it is the one tool that reads the network, and it writes nothing but the cache `citations audit` keeps. Each write is one line of the draft, in the file's own line endings, and no other byte changes. Nothing else the server offers freezes, registers, seals, runs a declared command or fetches, and its instructions carry the `open-items` procedure and tell the agent to ask a person for those.
