**[reproducible-science] A tool is detected by what it can act on, not by a directory name.** `claims` is an ordinary word: a Python package and a knowledge-graph registry were both read as citations projects and then failed for holding no quotations. `prereg check` looks for a file named `PREREG.md`, while detection looked for a directory named `preregs`, so a directory of hand-named plans was reported as a project whose registrations were broken. An empty directory no longer counts as use.
