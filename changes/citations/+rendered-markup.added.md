**A quotation from a page's source can be written as the page renders it.** Where the source is text read off disk as `.md`, `.markdown`, `.rst` or `.txt`, the second reading reduces each MyST or Verso role to its text and drops each HTML tag, so `{kw}`#print axioms`` is quoted as `#print axioms` and `<b>cache verification</b>` as `cache verification`. A quotation that kept the markup still resolves. HTML, XML and a file with no suffix are read as before.
