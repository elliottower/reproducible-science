**A service that did not answer is no longer counted as one that found nothing, and `citations audit --strict` exits 2 when a lookup could not be made.** `resolve.get` read every HTTP error it did not retry as an answer holding nothing, so a Semantic Scholar 403, a 401, a 400 or a 500 counted that service among those a `not found` rested on. It now has three outcomes besides a payload: a 404 or 410 is an answer that the work is absent; a 400 or 422 raises `Rejected`, an answer about the query that asking again will not change; and a 401, 403, 429, 5xx or timeout raises `Throttled` (any 5xx is retried like a 503); a rejected query is never retried with the OpenAlex key, and a 401 or 403 is retried with it once. `citations resolve` never counts a rejected query toward its stop after four records in a row are refused, and `citations add` reports a rejected DOI or arXiv id as `rejected the identifier as malformed or unknown`, with arXiv's own error message, rather than `try again later`. In `citations audit` a title search is `not found` only when Crossref or OpenAlex answered, whatever the other services did; the services that refused are listed under `refused` and the services that rejected the query under `rejected`, and both are named on the entry's line (`Semantic Scholar could not be asked`, `Crossref rejected the query`). A search in which neither Crossref nor OpenAlex answered is `could not check`. The audit's registry fetch had one `unresolved` row for a DOI no registry holds and for a Crossref that timed out; that row is now `not found` where every registry asked answered 404, 410, 400 or 422, and `could not check` where any refused, timed out or returned a body that is not a record. Under `--strict`, `could not check`, and an audit in which nothing was checked (every entry `no id` under `--no-search`, for one), exits 2, so a CI job can retry instead of blaming the citation; a disagreement or an unlisted not found exits 1 whatever else could not be checked. The `--json` report is written before the summary is printed.
