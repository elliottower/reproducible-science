**`citations pin --url URL` pins a quotation against a web page.** The page is obtained through [`retrieved`](https://github.com/elliottower/retrieved): the most recent retrieval of that URL in the `retrieved` library is read where there is one, and the page is captured through `retrieved`'s denylist, pacing and fetch where there is none; `--recapture` fetches it again. The claims file, which need not exist, is written with the URL, the sha256 of the bytes, the retrieval time as `retrieved_at`, and `retrieved: store/<sha256>`, a path inside the library, so the file names no directory of the machine that wrote it and the page is never copied into the project. An HTML page is checked as the text it shows, through the new built-in extractor `html-text`, which drops tags, decodes character entities, leaves out `<script>` and `<style>`, and writes a table row with ` | ` between its cells; the claims file names it with `extractor_version` and `derived_sha256`, so `verify` reads the page the same way. Other text is read as served and a PDF by the PDF readers. A local `.html` file that declares nothing is read with its markup as before, and can name `extractor: html-text`. The library is `$RETRIEVED_HOME`, else the nearest `.retrieved/` at or above the directory holding `claims/`, else a new `.retrieved/` there. A URL `retrieved` refuses, a server error and a failed request exit 1 with the reason and write nothing. A claims file pins one retrieval: `--url` on a file that pins another retrieval or another source is refused. `citations verify` reads the page from the library and reports `unchecked`, naming the store, where the library does not hold it; `citations fetch` keeps a new download only where it matches the pin, and otherwise says the page may have changed since the retrieval time. `retrieved` is installed by the new `web` extra, `pip install "citations[web]"`; without it `pin --url` names the install and every other command is unchanged.
