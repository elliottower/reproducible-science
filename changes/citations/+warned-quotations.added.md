**`citations verify` says which quotations carry each warning.** It counted the `short`, `truncated`, `normalized` and page warnings and named none of them, so finding the 36 short and 7 truncated quotations in one paper meant calling `check_one` from a script. `--verbose`, which was accepted and did nothing, now lists the claims file, claim and quotation under each warning, and `--json` writes the same under `warnings`, with each quotation's outcome.
