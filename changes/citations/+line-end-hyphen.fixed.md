**A real hyphen at a line end, and a space a page sets before punctuation, no longer make a quotation `normalized`.** Folding removes a hyphen at a line break between two letters, so a source breaking `open-access` as `open-` over `access` read `openaccess`, and the quotation as written resolved only with spacing and hyphens ignored. A page rendering `dvc.lock , including` did the same to `dvc.lock, including`. A passage folding does not find is now looked for verbatim in a second reading that keeps that hyphen and closes the space before a closing mark or after an opening one; it removes only white space. A quotation found there carries no warning, and is `truncated` only where it cuts a word in both readings, so one ending on `some` where layout set `some-` at a line end beside the next column's `class` is no longer called truncated.
