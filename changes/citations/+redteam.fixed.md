**A quotation that is in its source and may misstate it is now warned, and `--strict` fails the ones whose words are not the source's.** `citations verify` reads the source around each found passage and adds seven warnings: `after negation` (the passage begins mid-sentence after `no`, `not`, `without` and the like), `after hedge` (after `may`, `whether`, `suggest`), `quoted in source` (inside the source's own quotation marks), `references` (only in the reference list), `superscript` (`x²` matched as `x2`), `joined` (matched only by joining `not able` into `notable` or `1 2.5` into `12.5`), `split` (the reverse, `notable` quoted as `not able`, which is also what an extractor that drops a space produces), and `invisible` (white, sub-point or off-page text in a PDF, where `pypdf` and `pdfplumber` are installed). `--verbose` and `--json` show what the source reads there. `--strict` now fails `joined` and `invisible`; the default exit code is unchanged. The others are read off the text around a match or off a page number, by rules an honest quotation trips, and are warnings under `--strict` too: a heading run into the next line reads as a negation before a passage, an appendix with no `Appendix` heading as part of the reference list, and a journal's page 475 is page 2 of the article's PDF. `citations pin` refuses a `joined` match and pins a `split` one and appends every pin to `claims/pins.jsonl`, keyed by the source and by each quotation's sha256 and digest rather than by the claims file's name, which a rename changes. `verify` reports a source pinned again against other bytes, quotations no pin recorded, and fails on lines git history shows taken out of the log while their quotation stays; a line taken out by a `git revert` of the commit that added it, read from a change that exactly undoes that commit, file by file, and never from the message alone, and only where the quotation went with it: a line taken out while its quotation stays fails, whatever took it out, or with its quotation, is a note saying how to put it back. A merge commit is read against its parents, so a line taken out inside a merge fails too. Where `citations[pdf]` is not installed, `verify` says once that the invisible-text check did not run. For a source that is absent, `verify` checks that its sha256 and DOI have the right shape, failing `--strict` where they do not. `citations coverage` reads straight and curly quotation marks, `\enquote`, the `quote` and `quotation` environments and Markdown `>` blocks, lists each quotation covered only with an ellipsis together with the text it leaves out, and fails `--strict` where that text holds a negation.
