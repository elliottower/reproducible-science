**`citations manual-check` records that a person compared a quotation with the page, and `citations verify --json` carries the record under `manual_checks`.** A manual check is optional provenance beside the automatic check: it changes no outcome and no exit code, and `verify` prints nothing about it unless `--show-manual` asks. `citations manual-check <claims-file> <id> [--page N] [--note TEXT]` prints the quotation, its source and page, and appends a line to `claims/<stem>.manual.txt` with the quotation's fingerprint; it takes one id per call, refuses an id naming no quotation, one listed already with its current fingerprint, an argument it does not take, a page below 1, and a line the list would not read back as written, and replaces a stale line only with `--again`, which keeps that line's page and note unless new ones are given. It also refuses a list that is not a regular file and a line that would take the list past 1 MiB. It reads and writes the list under a lock on the file the list resolves to, so concurrent calls each keep their line, through two links to one list as well, and keeps the list's byte-order mark and line endings; the lock's sidecar is `<stem>.manual.txt.provenance-lock`, which the `.gitignore` `repro init` writes already ignores. Ids are compared in Unicode NFC on the list and in the claims file, and written in NFC. The id is the claim id where the claim has one quotation, or `<claim id>/<n>`. The fingerprint is of the quotation's text, the source's `sha256`, its declared reader, and the reading: `derived_sha256`, or where none is recorded the digest of the text extracted; the extractor's version string is not in it. The JSON gives the lists' SHA-256s and one digest over them, each covered quotation with its computed outcome, page and note, the counts by outcome, the stale entries with the fingerprint each has now, the unverifiable entries whose source is not on this machine and whose claims file records no `derived_sha256`, ids naming no quotation, lists beside no claims file, and lines that did not parse or name a quotation twice. A list that cannot be read, is not a regular file, or is larger than 1 MiB, is recorded with no entries; a FIFO is opened without blocking, so `verify` does not wait on one. None of these changes the output or the exit code.
