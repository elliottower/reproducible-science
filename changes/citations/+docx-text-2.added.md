**`docx-text` version 2 reads a `.docx` from its own XML, with nothing left out of what the document says.** It reads the body in document order, with each table where it stands, a table nested in a cell after its row, text boxes, content controls (a reference manager's citations among them), hyperlink text and the result of every field, and an equation's characters; then each footnote and endnote, marked `Footnote 1.` and `Endnote 1.` in the order the text refers to them; then each header and footer once. Tracked changes are read as accepted. Comments are not read. It needs no library: `python-docx` is now needed only for version 1. A part declaring a document type and a file whose XML inflates past 128 MiB are refused as unreadable. A source recording `extractor_version: 1` is still read by version 1, so its `derived_sha256` still holds; a `.docx` naming no version, and every new pin, is read by version 2. A claims file naming a version no build ships is told every version this one does.
