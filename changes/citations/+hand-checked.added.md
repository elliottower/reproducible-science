**`citations verify` reads which quotations an author compared against the rendered page, and reports them beside their computed outcomes.** The list for `claims/<stem>.yaml` is a plain file beside it, `claims/<stem>.checked.txt`: one quotation per line, named by its claim id where the claim has one quotation or `<claim id>/<n>` for its n-th, then the 12-character fingerprint verify gives it and optionally the page as `p.N`, with `#` for a note. A listed quotation keeps its outcome: one not found is still `not found`, still fails the run, and is marked `(checked by hand)` in the list of those not found. The report prints `checked by hand: <n> of <quotations> passages, list sha256 <digest>`, one digest over every list read, and the computed outcomes of those covered. The fingerprint is of the quotation's text and the source's `sha256` and `derived_sha256` as the claims file records them, so a quotation edited after it was listed, or a source pinned again, is reported as no longer covered, with the fingerprint it has now; a line with no fingerprint is reported the same way. An id naming no quotation in its claims file is reported. `--json` carries the lists with their paths and SHA-256s, each covered quotation with its outcome, page and note, the stale and unknown entries and the counts by outcome under `checked_by_hand`. No outcome and no exit code changes.
