**`prereg status` reads from OSF whether the plan's registration is pending approval, embargoed, public or withdrawn.** It sends one GET per registration and writes nothing, on OSF or in the log, so it asks for no phrase. A pending registration is reported with the time after which OSF approves it itself, 48 hours from submission. It exits 0 for a registration in effect, 2 for one pending or not yet made, and 1 for one withdrawn or not readable; run where no plan governs, it reports every plan below. `prereg` does not approve a registration: OSF's API has no request by which an admin approves their own, so that is done from the email OSF sends or left to the 48 hours.
