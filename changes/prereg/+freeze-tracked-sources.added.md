**`prereg freeze` names the pinned sources git tracks.** A freeze names a commit, and a source text in that commit can only be removed later by rewriting history, which changes the commit's identifier. Where `citations` is on `PATH`, the freeze runs `citations lint --claims --json` beside the plan and prints how many pinned sources git tracks, the first ten by path, and that sentence. It is a warning printed after the freeze's own report: the record, the files written and the exit code are unchanged. Nothing of `citations` is imported, and with no `citations` installed, no claims directory, or nothing tracked, nothing is printed.
