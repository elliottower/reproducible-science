**The `prereg` plugin recognises a frozen file by the rule the mod uses.** A corrupt or unreadable freeze record let the edit through, and a `**Plan sha256:**` line made any `.md`, `.markdown` or `.txt` file frozen while a file with a freeze record and another suffix was not. `frozen_file_before_edit.py` now denies an `Edit`, `Write` or `MultiEdit` to a file of any name wherever `.prereg/<name>.json` exists beside it, whatever the record holds, and applies the `**Plan sha256:**` rule only to a file named `PREREG.md`. `frozen_plan_changed.py` is unchanged.
