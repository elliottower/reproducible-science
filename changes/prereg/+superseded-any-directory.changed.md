**A draft's `Superseded by` line reads the same from any directory, may name a plan the tool froze, and a withdrawal carries the commit that declared it.** `prereg check` looked a successor up among the documents at or below the directory it ran in, so `exp/DRAFT.md` naming `../PREREGISTRATION.md` was `superseded` from the repository's top level and `pending`, exit 2, from `exp/`. The path is now looked up in the whole repository, read from the draft's own directory, and the draft has one status wherever the check runs. A run in a subfolder lists the same documents as before: a successor above or beside it settles the draft without being listed. A path that is absolute or leaves the repository leaves the draft `pending` and says so. A draft may name a `PREREG.md` frozen with `prereg freeze`, which used to read as "not a registration checked here": the plan is checked as `prereg check` checks any plan, the draft is `superseded` only where that check passes, and a plan that is not frozen or was changed after its freeze leaves the draft `pending` with the reason. Neither header line is read on a `PREREG.md` itself. A `withdrawn` document's report gains a line naming the commit that added its `**Withdrawn:**` line and that commit's date, followed across renames, or saying the line is not yet committed; the status and the exit code are as they were.
