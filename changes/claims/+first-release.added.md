**`claims-cli` is the part of Reproducible Science that checks what a manuscript states against its files, installable by itself.** `pip install claims-cli` installs the command `claims` and the package `claims`, with `citations` and nothing else of ours: `claims verify`, `claims stale`, `claims why`, `claims numbers`, `claims export` and `claims manifest init` are the commands `repro` has under those names, the same functions reading the same `repro.yaml` and printing the same output. It runs no command a manifest names and drives no other tool; `repro reproduce`, `repro check`, `repro audit` and `repro ci` stay in `reproducible-science`, which depends on this. Where a message tells the user what to type, `claims` names its own command (`claims manifest init`), and names `repro reproduce` with the distribution that provides it. The optional readers are extras of this distribution: `arrays`, `hdf5`, `netcdf`, `parquet`, `rds`, `sheets`, `stata-spss`. Installed without `reproducible-science`, a decision names `claims-cli` as the tool that read the artifact and carries its version, and a hint for a missing reader says `pip install "claims-cli[sheets]"`; installed with it, both are what they were.
