**`claims from-clew` reads a SciTeX Clew `claims.json` into check records.** Each claim of the export becomes one record of each check Clew's stored status says it ran, with `scitex-clew` as the checker and its status as `native_outcome`: an `artifact-identity` record for the source file's sha256 (a match for `verified` and `suspect`, a mismatch for `mismatch`, not-checked for `registered`, `missing` and `superseded`), and a `lineage-check` record where Clew walked the sessions upstream of the file (a mismatch for `suspect`, a match for `verified`, and not-checked where Clew's chain flags resolve a verified claim to `exception`, `frozen` or `unsourced`). Clew compares no value, so no record is a `value-comparison`, and `claim_value` is carried as written in a field of its own. Clew's naive local times are refused unless `--offset +HH:MM` states the offset of the host that wrote them, and never read as UTC. Paths are written from `--root`, the folder holding `.scitex` by default, and a path outside it as its file name, with a warning. Only export schema `1.4` is read. The reader reads the exported file only and imports no Clew code.
