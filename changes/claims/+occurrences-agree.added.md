**A `correspondence` takes two sides or more, and every pair must agree, so a number printed in several places of a manuscript is checked place against place.** An abstract printing 8.3% and a section printing 8.4% each agree with a stored 0.0835, which is an exact tie at one decimal, and so passed when each place was compared with the file alone. With a side per place the assertion is a `mismatch`, and its detail names each side with its artifact and value and then each pair that disagrees. A prose locator also takes `form: grouped`, which reads `1,062` as 1062. A two-sided correspondence is checked and reported as before.
