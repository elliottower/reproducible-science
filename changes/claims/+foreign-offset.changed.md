**`claims from-clew` and `claims from-paperdelta` read `--offset` by one rule and refuse an existing `--output` the same way.** An offset is `+HH:MM` or `-HH:MM`, from `-23:59` to `+23:59`; `+0900` is refused by both, and a negative one is taken as `--offset -05:30` or `--offset=-05:30`. A time that carries its own offset keeps it. An `--output` that exists is refused with exit 2 and the file left as it was, by both commands, as is one in a folder that does not exist, named as given.
