**`reproducible-science-ui`, a local web page over a project's records, served by `repro ui`.** It shows the claims a manuscript makes and whether each still holds, the files each claim reads, the runs that wrote them with their outside records, the pinned quotations by the sections that cite them, and the rebuild steps with every re-run, with a lineage graph of the files and runs behind each claim. The page re-reads the records by itself and writes nothing; repro verify and repro reproduce ask before they run and say what they write. Its data stays inside the project's git directory. Development Status: Alpha.
