**The page offers one way to act on each problem.** The request queue for Claude Code and its endpoint are gone. A failing claim, and all of them together on the Claims tab, have **Copy prompt**, which puts a prompt on the clipboard for any agent; the prompt asks the agent to look into the failure and lay out the options, then to wait for the person to choose, and never asks it to change anything. The top bar holds two counts and two commands: `● 531/531 claims verified`, which opens the Claims tab; `◐ 18/20 reproduced`, which opens the Reproduce tab; then `repro verify ▾` and `repro reproduce ▾`. There is no Refresh button: the page re-reads the records, which writes nothing, when its tab comes back into view and every 30 seconds while in view. The project's name moves to the browser tab's title. `repro reproduce ▾` lists the rebuild steps with the changed ones first and **Run N changed**; a re-run's output comes into the dialog as `repro reproduce` prints it, with the seconds ticking, and ends on what it found in words, such as `1 reproduced · 11.62 s`. Every step shows how long its last re-run took. **Copy command** gives `cd <project> && repro reproduce --only <step>`, quoted for the shell, for any terminal, never the step's own script. A page that closes mid-run does not stop the run, which is recorded and shown on the next load. A request from a page loaded before the server restarted is answered "This page is out of date: reload it."; one from anywhere else, "Refused: not a request from this page."
