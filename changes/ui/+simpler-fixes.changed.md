**The page offers one way to act on each problem.** A failing claim, and the failing count, have **Copy prompt to fix**, which puts a prompt on the clipboard for any agent; the request queue for Claude Code and its endpoint are gone. The top bar holds two counts and two buttons: `● 531/531 claims verified ▾`, which lists any failing claims and the counts by section; `◐ 18/20 reproduced ▾`, which opens the rebuild steps with the changed ones first and **Run N changed**; then Refresh and repro verify. The project's name moves to the browser tab's title. A re-run's output streams into the dialog as it runs, with the seconds ticking, and ends on what it found in words, such as `1 reproduced · 11.62 s`; every step shows how long its last re-run took. **Copy command** gives `cd '<project>' && repro reproduce --only <step>` for any terminal, never the step's own script. A request from a page loaded before the server restarted is answered "This page is out of date: reload it."
