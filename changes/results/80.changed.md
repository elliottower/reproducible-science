**[results-cli] `results init` writes a `.results/.gitignore` that ignores only the lock files.** The ledger and its anchor are then committed with the project by default. `results verify` reported an untracked ledger as a record nobody else can check, and nothing made tracking it the default. A committed ledger is public with the repository, so a run's `note` is written as a commit message would be. A project whose own `.gitignore` lists `.results/` is unaffected until that line is removed.
