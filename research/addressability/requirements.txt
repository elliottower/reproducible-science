# Pinned so the study's network behaviour does not depend on the machine that ran it.
#
# certifi supplies the CA bundle explicitly. Without it, Python on macOS raises
# CERTIFICATE_VERIFY_FAILED on every HTTPS lookup and falls back to the operating system's
# trust store elsewhere -- so the same script would resolve different numbers of snapshots
# on different machines, and the retrieval rate would be a property of the environment
# rather than of the literature.
#
# This was not hypothetical. Before it was pinned, every Software Heritage lookup failed on
# certificate verification, the failure was swallowed, and 42 articles with resolvable
# snapshots were being coded `absent`.
certifi>=2024.2.2
